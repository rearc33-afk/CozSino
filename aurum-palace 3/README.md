# Aurum Palace

A first-person 3D casino maze that runs in the browser. Wander a windowless, dimly lit floor of warm reds, oranges and gold packed with fake players, then sit down at slots, blackjack, five card draw, Texas Hold'em or roulette. Play money only.

No dependencies. `index.html` is a single self-contained file (styles and scripts inlined), so it works on its own: double-click it, or host it anywhere.

## Features

- **An open floor with a maze in the carpet.** There are no inner walls. A maze is generated from a seed (Kruskal's algorithm plus extra loops) and printed on the carpet as golden ribbons that wind between seven large gaming rooms (corners, plus the top, left and right) and a central atrium with the jackpot pillar. Banks of slot machines stand back to back along the maze lines, so you can see the maze from across the floor and still walk anywhere.
- **Packed floor.** Around 200 people: players on stools at slot machines, dealers, patrons at card tables and roulette, and about 45 guests following the carpet paths. They celebrate wins with a cool strobe flash and a positional jingle.
- **Lighting.** Dim, warm and gold on the floors, walls and ceiling; cool white on the tables and their light shafts. Cool lights flash all over the floor, ceiling bulbs chase in warm and cool waves and string along the walls, and a jackpot makes everything strobe.
- **Constant casino noise.** Reel rolls, coin showers, bells, jackpot melodies and sirens are synthesized live with Web Audio, with no audio files. The mix gets louder near the slot room and muffled behind walls.
- **Five games, seven rooms.** Two of the games get a second room.
  - *Slots*: 3x3 reels, 5 paylines, wilds, scatter free spins (wins pay double), a progressive jackpot, and a red/black gamble.
  - *Blackjack*: six-deck shoe, split, double, insurance, Perfect Pairs side bet, optional Hi-Lo count.
  - *Texas Hold'em*: you against three table bots, fixed limit. Everyone antes, then four betting rounds (pre-flop, flop, turn, river) with check, bet, call or fold. Best five of seven cards wins.
  - *Five card draw*: you against two table bots with ante, hold and draw, then check, bet, call or fold.
  - *Lightning roulette*: single zero, three lucky numbers each spin paying 50x to 500x, camera zoom on the wheel.
- **Explore.** Gold chips are hidden at the dead ends of the carpet maze, marked with small diamonds. A fog-of-war minimap fills in as you walk (Tab or tap to enlarge).
- **Your night.** You start with $5,000, saved in your browser. You sign in on the home screen with an email and a username (no password; it only keys your saved chips in this browser). The leaderboard (L or the button) lists the real accounts on this browser, no fake players. Hit $0 with nothing left on the table and security walks you out: the night is marked "Kicked out" and you can start a new one. The board is local to your browser, there is no server.
- **Mobile.** Touch controls: left thumb walks, right thumb looks.

| Input | Action |
| --- | --- |
| W A S D / arrow keys | Walk |

| Esc | Leave the table |
| Tab | Enlarge the minimap |
| L | Leaderboard |

## Run it

```bash
git clone <your repo url> aurum-palace
cd aurum-palace
npm start            # serves http://localhost:8080 (uses python3)
# or: npx serve .
```

Double-clicking `index.html` also works in most browsers.

three.js r128 loads from cdnjs. For fully offline play, save `three.min.js` into `vendor/` (see `vendor/README.md`).

## Put it on GitHub Pages

1. Create a repository and push this folder to the `main` branch.
2. In the repository go to Settings, Pages, and set Source to **GitHub Actions**.

`.github/workflows/pages.yml` runs the tests and publishes the site on every push.

## Single file build

```bash
npm run build        # writes dist/aurum-palace.html, one self-contained file
```

## Project layout

```
index.html            the bundled game, generated by `npm run build` (commit it)
dev.html              the unbundled page shell and script order; edit this, then rebuild
css/style.css         HUD, panels and game UI
js/util.js            helpers, seeded random numbers, storage
js/maze.js            maze generator and pathfinding (pure logic)
js/carpet.js          paints the maze onto the floor texture
js/engine.js          renderer, lights, canvas textures, materials, geometry batching
js/props.js           slot machines, tables, roulette wheel
js/npcs.js            the crowd (instanced meshes, seated and walking people)
js/build.js           builds the floor, outer walls, rooms, props and crowd from a maze
js/anim.js            strobes, flashes, wheels, jackpot display, pickups
js/audio.js           synthesized casino soundscape
js/ui.js              bank, jackpot, toasts, card helpers
js/games/             slotmath, pokermath (pure) and the five game panels
js/world.js           player, input, minimap and the render loop
tools/                tests and the bundler
```

All files are plain scripts sharing one global, `Casino`, so there is no bundler and nothing breaks when opened from `file://`.

## Tests

```bash
npm test
```

- `test-maze.js`: 300 seeds all produce fully connected mazes with 3+ doors on every room.
- `test-slots.js`: Monte Carlo run of the slot maths (about 95% return before the jackpot).
- `test-poker.js`: hand ranking cases.
- `smoke.js`: runs the whole game, 400 frames and hundreds of hands, against stubbed 3D and DOM objects to catch runtime errors. It cannot judge how the game looks.

## Tweaking

- Maze size: `COLS`, `ROWS`, `CELL` in `js/maze.js` (room placement assumes 3x3 cell rooms at the corners). The layout seed is the number passed to `W.newMaze` in `js/world.js`.
- Crowd: seat fill odds are in `js/build.js` (`s.p`, `walkers`).
- Payouts: `SYMS` in `js/games/slotmath.js`, then re-run `node tools/test-slots.js`.
- Lighting mood: fog, hemisphere and player light in `js/engine.js`.
